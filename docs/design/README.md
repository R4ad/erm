# مرجع طراحی: شناسایی ریسک از پاسخنامه

خروجی فایل فیگمای «ERM — سامانه مدیریت ریسک سازمانی» (صفحه‌ی «۰۲ — صفحه‌ها»)، گرفته‌شده روی لپ‌تاپ طراح. سرور توسعه به فیگما دسترسی ندارد، پس **این پوشه تنها مرجع طراحی** است.

| فایل | محتوا |
|---|---|
| `frames/*.png` | تصویر هر فریم در اندازه‌ی واقعی (عرض ۱۴۴۰). `30e.png` به‌خاطر ارتفاع زیاد با مقیاس ۰٫۹ ذخیره شده است. |
| `copy.md` | همه‌ی متن‌های فارسی، **عیناً** از لایه‌ها |
| `layout.md` | ساختار، اندازه‌ها، فاصله‌ها و توکن رنگ هر ظرف |
| `components.md` | مشخصات کامپوننت‌های سیستم طراحی (دکمه، نشان، تب، فیلد، …) |
| `tokens.json` | رنگ‌ها، سبک‌های متن، گردی‌ها و ابعاد پوسته (تم داتین) |
